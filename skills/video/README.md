# Video shelf

Skills that make videos from code.

- `html-video`, brief to MP4 via deterministic HTML animation, Playwright, and FFmpeg.
  Proof: `html-video/examples/vlan-explainer/`, a 30-second vertical
  VLAN explainer with its prompt, animation source, and render.
- `manim-explainer`, math and science explainers in Python Manim:
  concept to beats, low-quality timing pass first, TeX-free by
  default on small servers, frame-verified delivery.
