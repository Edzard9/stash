# Examples

Finished renders live here, each in its own folder with:

- the rendered `video.mp4`
- the `animation.html` that produced it
- `PROMPT.md`: the exact prompt given to the agent

## Planned first example

**vlan-explainer** — a 30-second vertical video answering "What is a VLAN?" in five scenes, produced end to end by the `html-video` skill from a single prompt. It doubles as the project's proof that the whole pipeline works on an ordinary laptop.
