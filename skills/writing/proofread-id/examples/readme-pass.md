# Example: a real proofread pass

Source: the Bahasa Indonesia section of this repo's own main README,
run through this skill on 8 November 2026. The text was already
fairly clean, which is normal; the pass found register and word-choice
edits, listed below by type, and the cleaned text was applied to the
README itself.

## Changed

**Diksi (word choice), 1x**
- "tautkan sumbernya sebagai etiket" becomes "tautkan sumbernya
  sebagai bentuk atribusi". "Etiket" means a label or etiquette; the
  intended meaning was attribution.

**Register kalimat, 2x**
- "Soal memakai skill orang lain, repo ini mengikuti empat tingkat:"
  becomes "Terkait penggunaan skill orang lain, repo ini mengikuti
  empat tingkat ketentuan:" ("Soal" as a sentence opener is
  journalistic, not formal.)
- "Commit tanpa co-author AI." becomes "Commit ditulis tanpa
  co-author AI." (a fragment gains its verb; the rule reads as a
  sentence.)

**Konsistensi istilah, 1x**
- "yang kamu mau" becomes "yang kamu inginkan" in the usage
  instructions, matching the formal register of the surrounding
  rules section.

## Flagged, not changed

- "Satu PR menambah satu skill." Kept. "PR" is the established term
  in this repo's context and the sentence is correct as written.
- All facts, links, and the four-tier source policy wording were
  left untouched, per the skill's ground rule: language only.
