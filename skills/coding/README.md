# Coding shelf

Skills about writing, reviewing, and refactoring code.

Residents:

- `oss-contributor`, the external-contribution playbook: house rules
  first, three-layer claim screening, repo-pattern mirroring, honest test
  reporting, clean PRs.
- `small-briefs`, the delegation discipline: split a big build into
  small sequential briefs for a coding agent, one outcome and one
  finish line each, verified piece by piece.
- `lean-code`, planned: the maintainer's own concise-code skill, fetched
  from his machine.
