# Coding shelf

Skills about writing, reviewing, and refactoring code.

Residents:

- `oss-contributor`, the external-contribution playbook: house rules
  first, three-layer claim screening, repo-pattern mirroring, honest test
  reporting, clean PRs.
- `small-briefs`, the delegation discipline: split a big build into
  small sequential briefs for a coding agent, one outcome and one
  finish line each, verified piece by piece.
- `cloudflare-worker`, Workers + D1 in the shape that survived
  production: route-based structure, migration discipline (including
  the "no such table" trap), secret hygiene, defensive email parsing.
- `laravel-patterns`, Laravel architecture (thin controllers,
  services/actions, Eloquent without N+1, scoped bindings). Adapted
  from affaan-m/ECC (MIT).
- `laravel-security`, the Laravel hardening checklist with teeth:
  production config, token abilities, policies, mass-assignment and
  injection safety, rate limits. Adapted from affaan-m/ECC (MIT).
- `react-patterns`, React 18/19 discipline: pure render, hooks rules,
  a state-location decision tree, server/client boundaries. Adapted
  from affaan-m/ECC (MIT).
- `nextjs-turbopack`, Next.js 16+ guidance including the proxy.ts
  rule reviewers keep getting wrong. Adapted from affaan-m/ECC (MIT).
- `lean-code`, planned: the maintainer's own concise-code skill, fetched
  from his machine.
