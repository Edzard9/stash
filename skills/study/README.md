# Study shelf

Skills for learning: interactive figures, summaries, drills.

- `lab-report`: practicum reports in one fixed house format (identity
  header, per-point observations with a one-line "what it means",
  conclusion, observation table, Q&A evaluation answers). Includes a
  worked example from a real Inter-VLAN Routing practicum.
- `net-lab`: the Packet Tracer companion discipline. The module wins,
  one device per short paste block, interface names in full, every
  stage validated, calm at harmless accidents. Includes the field
  notes and a real session recap.
- `study-notes`: lecture material into compact notes plus
  question=answer flashcards, one pair per line, paste-ready for
  quiz tools. Worked example from real networking material.
- `interactive-figure`: single-file HTML figures a student can
  click, break, and watch respond, with a live readout and a reset.
  Ships a wired template and a finished VLAN isolation figure.
- `anatomy`: the isometric-figure method (the object is the
  explanation), condensed into agent-neutral steps. Universal
  adaptation of wheresryan22/anatomy (MIT); the drawing kit stays in
  the original repo.
- `cisco-ios-patterns`: IOS review patterns, wildcard masks, ACL
  placement, and safe change windows. Adapted from the ECC
  collection (MIT).
