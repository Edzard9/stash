--- ISSUE #2: [Tool] Kalkulator IPK dan SKS / GPA Calculator ---
Labels: tool, good first issue, kategori:kuliah

What to build
A GPA calculator with dynamic course rows and an optional cumulative mode that combines previous semesters.

Scope
- Dynamic rows (add/remove): course name (optional), credits/SKS (1-6), letter grade (A=4, AB=3.5, B=3, BC=2.5, C=2, D=1, E=0).
- Live results: total credits and this semester's GPA.
- Optional inputs: previous cumulative GPA + previous total credits, producing the combined cumulative GPA.

Acceptance criteria
- Hand-checked example: two courses (3 SKS A, 2 SKS B) yield GPA 3.60.
- All values update in real time on any input change.
- Fully bilingual UI; works offline; no dependencies.
